# ViralValue starter website

This is a static website for the ViralValue digital discovery / affiliate brand.

Files:
- index.html
- about.html
- disclosure.html
- privacy.html
- style.css

Before publishing:
1. Replace the TikTok placeholder link in index.html with your real TikTok profile.
2. Add your business email.
3. Review the privacy policy for your actual analytics, cookies, forms, hosting and affiliate networks.
4. Add real product/tool review pages and real affiliate links only after you are approved for the relevant programs.
5. Connect a domain you control.

Deployment:
- GitHub Pages can publish static HTML/CSS from a repository.
- Cloudflare Pages can deploy a static HTML site and provides a pages.dev subdomain.

Do not claim endorsements, testimonials, traffic numbers, or partnerships you do not have.
